Скрипт для автоматического форматирования исходного текста программы. По умолчанию обработка выполняется рекурсивно для всех подходящих файлов.

Для того чтобы запустить данный скрипт, нужно выдать права на исполнение:

```shell
chmod +x code_style.sh  
```

Для того чтобы запустить данный скрипт:

```shell
./code_style.sh  
```

Скрипт может быть запущен со следующими флагами:

|Флаг|Описание|
|-|-|
|`-h`, `--help`|Показать справку|
|`-t`, `--type`|Указать формат форматируемых файлов. Доступные форматы: `c`, `sh`, `h`|
|`-f`, `--file`|Указать конкретный файл для форматирования|

> **Примечание**
>
> При одновременном использовании флага `-f` (`--file`) и `-t` (`--type`) флаг `-t` (`--type`) не учитывается.

> **Особенности форматирования**
>
> Для исходного текста программ на языке Си используется стиль Microsoft.

**Зависимости**

- [shfmt](https://man.archlinux.org/man/shfmt.1)
- [clang-format](https://clang.llvm.org/docs/ClangFormat.html)
